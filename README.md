\# AgriOS



AgriOS is a multilingual, mobile-first farm operations assistant.



The first release is focused on helping a farmer in Haryana:



\- Create a farm and field

\- Start a wheat crop cycle

\- View an editable crop-task calendar

\- Track irrigation and expenses

\- Check weather information

\- Find sourced government scheme information



\## Current status



Project foundation is under development.



\## Technology



\- React and TypeScript frontend

\- FastAPI backend

\- SQLite during initial development

\- PostgreSQL planned for deployment

\- Pytest for backend testing
